# C# Exceptions

Handling errors in C# using try/catch/finally and throwing exceptions.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-safe_list_print/` | Method to safely print n elements of a list |
| 1 | `1-divide_print/` | Method to divide 2 integers and print the result |
| 2 | `2-divide_lists/` | Method to divide element by element 2 lists |
| 3 | `3-throw_exception/` | Method that throws an Exception |
| 4 | `4-throw_exception_msg/` | Method that throws an Exception with a message |

## Requirements

- .NET SDK installed
- All files compiled and run with `dotnet run`
