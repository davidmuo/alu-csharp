# C# Arrays, Lists, and Dictionaries

Working with arrays, lists, and dictionaries in C#.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-print_array/` | Create and print an array of integers |
| 1 | `1-element_at/` | Retrieve an element from an array by index |
| 2 | `2-replace_element/` | Replace an element in an array at a given index |
| 3 | `3-print_array_reverse/` | Print all integers of an array in reverse |
| 4 | `4-print_list/` | Create and print a list of integers |
| 5 | `5-max_integer/` | Find the biggest integer in a list |
| 6 | `6-divisible_by_2/` | Find all multiples of 2 in a list |
| 7 | `7-delete_at/` | Delete an item at a specific position in a list |
| 8 | `8-number_keys/` | Return the number of keys in a dictionary |
| 9 | `9-add_key_value/` | Add or update a key-value pair in a dictionary |
| 10 | `10-delete_key_value/` | Delete a key from a dictionary |
| 11 | `11-multiply_by_2/` | Return a new dictionary with all values multiplied by 2 |
| 12 | `12-print_sorted_dictionary/` | Print a dictionary sorted by keys |
| 13 | `13-best_score/` | Return the key with the highest integer value |
| 14 | `14-rectangular_array/` | Create and print a 5x5 two-dimensional array |
| 15 | `15-square_matrix/` | Compute the square value of all integers in a matrix |

## Requirements

- .NET SDK installed
- All files compiled and run with `dotnet run`
