# C# HashSet, Stack, Queue, and LinkedList

Working with HashSet, Stack, Queue, and LinkedList in C#.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-unique_add/` | Add all unique integers in a list |
| 1 | `1-common_elements/` | Return a sorted list of common elements in two lists |
| 2 | `2-different_elements/` | Return a sorted list of elements present in only one of two lists |
| 3 | `3-stack_push_pop/` | Print, search, and update a Stack of strings |
| 4 | `4-queue_enqueue_dequeue/` | Print, search, and update a Queue of strings |
| 5 | `5-print_linkedlist/` | Create and print a LinkedList of integers |
| 6 | `6-linkedlist_length/` | Return the number of elements in a LinkedList |
| 7 | `7-linkedlist_add/` | Add a node to the beginning of a LinkedList |
| 8 | `8-linkedlist_find/` | Find the index position of a value in a LinkedList |
| 9 | `9-linkedlist_pop/` | Delete the head node of a LinkedList and return its data |
| 10 | `10-linkedlist_get_node/` | Return the value of the nth node of a LinkedList |
| 11 | `11-linkedlist_sum/` | Return the sum of all the data of a LinkedList |
| 12 | `12-linkedlist_insert/` | Insert a new node in the correct position in an ordered LinkedList |
| 13 | `13-linkedlist_delete/` | Delete the node at a given position in a LinkedList |

## Requirements

- .NET SDK installed
- All files compiled and run with `dotnet run`
