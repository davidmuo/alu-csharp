# C# - Test Driven Development

Projects implementing TDD with NUnit in C#.

## Tasks

- **0-add**: Method that adds 2 integers
- **1-divide**: Method that divides all elements of a matrix
- **2-max_int**: Method that returns the max integer in a list
- **3-palindrome**: Method that checks if a string is a palindrome
- **4-unique**: Method that returns index of first non-repeating character
- **5-camelcase**: Method that counts words in a camelCase string
