# C# Structs and Enums

Working with enums, structs, constructors, and method overrides in C#.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-dog/` | Define an enum Rating with values Good, Great, Excellent |
| 1 | `1-dog/` | Define a struct Dog with name, age, owner, and rating |
| 2 | `2-dog/` | Add a parameterized constructor to struct Dog |
| 3 | `3-dog/` | Override ToString() to print the Dog object's attributes |

## Requirements

- .NET SDK installed
- All files compiled and run with `dotnet run`
