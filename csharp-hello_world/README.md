# C# Hello World

Introduction to C# programming — initializing, building, and running projects with `dotnet`, plus basic output and string manipulation.

## Tasks

| # | File | Description |
|---|------|-------------|
| 0 | `0-initialize_new_project.sh` | Initialize a new C# console project |
| 1 | `1-build_new_project.sh` | Initialize and build a new C# project |
| 2 | `2-run_new_project.sh` | Initialize, build, and run a new C# project |
| 3 | `3-writeline/` | Print a string using `Console.WriteLine` |
| 4 | `4-print_integer/` | Print an integer with a string |
| 5 | `5-print_float/` | Print a float with 2 decimal precision |
| 6 | `6-print_string/` | Print a string 3 times and its first 9 characters |
| 7 | `7-concat/` | Concatenate strings to form a sentence |
| 8 | `8-print_variables/` | Print variables as a formatted string |
| 9 | `9-print_specifiers/` | Use percent and currency format specifiers |
| 10 | `10-copy_cut_paste/` | Extract substrings from a word |
| 11 | `11-concat_edges/` | Build a new sentence from string edges |

## Requirements

- .NET SDK installed
- Scripts must be run from the `csharp-hello_world/` directory
